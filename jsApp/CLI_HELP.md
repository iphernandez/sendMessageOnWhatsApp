# WhatsApp Group Chat - JS App

## Usage

```bash
node index.js [options]
```

## Options

- `--help`, `-h`
  Show this help message and exit.

## Examples

```bash
node index.js
node index.js --help
```

## Notes

- This legacy JS entrypoint sends the generated message using the values currently defined in `index.js`.
- To change the default group, schedule values, or template variables, update `index.js`.
