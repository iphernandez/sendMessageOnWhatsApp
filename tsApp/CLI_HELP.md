# WhatsApp Group Chat - TS App

## Usage

```bash
node index.js [options]
```

## Options

- `--help`, `-h`
  Show this help message and exit.

## Examples

```bash
node index.js
node index.js --help
```

## Notes

- This TypeScript entrypoint uses the values currently defined in `index.ts` to build the message.
- To change the default group, schedule values, or template variables, update `index.ts`.
